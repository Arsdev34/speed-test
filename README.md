# Internet Speed Test Script

Скрипт на Python для замера скорости скачивания данных с указанного URL.

## Как запустить

1. Установите зависимости:
   pip install requests

2. Запустите скрипт с URL (или без, тогда сработает URL по умолчанию):
   python speed_test.py https://example.com/image.jpg

## Единицы измерения скорости

Скрипт выводит скорость в KB/s (Килобайты в секунду) и Mbps (Мегабиты в секунду).
Формула для KB/s: (Общий объём в КБ) / (Среднее время запроса).
